# UB Korea 수요예측 도구

> Supabase 자동 저장과 동적 `Database Schema` 탭 설정은 [SUPABASE_SETUP.md](SUPABASE_SETUP.md)를 먼저 확인하세요.

에스파뇰라 스프레이(7종) · 산체스(4종) · 보르헤스(7종) · 에스테파(3종) — 총 21개 SKU의
24개월치(24.07~26.06) 실적이 이미 들어있어요. 매달 실제 실적을 입력하면서 예측을
쌓아나가고, 예측했던 값과 실제 값을 언제든 비교할 수 있어요.

## 핵심 개념 — vintage(예측 생성 시점)

`forecast` 명령을 실행할 때마다 **새로운 예측 기록**이 추가돼요. 예전에 만든 예측은
절대 지워지거나 덮어써지지 않아요. 그래서 "7월 초에 예측했던 9월 수요"와
"8월 말에 다시 예측한 9월 수요"를 나중에 나란히 비교할 수 있어요. 실제값이 들어오면
`compare` 명령으로 예측 대비 오차율(%)까지 자동 계산돼요.

## 설치

파이썬 3.8 이상이면 됩니다. 엑셀 내보내기 기능(`export`)만 openpyxl이 필요해요.

```bash
pip install openpyxl --break-system-packages
```

## VS Code에서 사용하기

이 폴더를 통째로 VS Code로 열면(`code demand_forecast_tool` 또는 파일 → 폴더 열기)
`.vscode/` 안에 미리 설정을 넣어놨어서 바로 쓸 수 있어요.

**사전 준비 — Python 확장 설치**
VS Code에 "Python" 확장(Microsoft 제공)이 설치되어 있어야 해요. 왼쪽 확장 탭에서
"Python" 검색해서 설치하면 돼요. 이미 설치돼 있으면 이 단계는 건너뛰어도 됩니다.

**실행 방법 — F5 한 번으로 끝**
1. 왼쪽 사이드바에서 "실행 및 디버그"(벌레 모양 아이콘, 또는 `Ctrl+Shift+D` / `Cmd+Shift+D`) 클릭
2. 상단 드롭다운에서 원하는 작업 선택:
   - **📋 목록 보기** — 상품 21개 전체 리스트
   - **📜 실적 이력 보기** — 특정 상품 실적 히스토리
   - **➕ 실적 입력** — 이번 달 실적 넣기 ★ 매달 반복하는 작업
   - **📦 현재 재고 입력** — 재고 실사값 등록 (최초 1회 + 재실사 시)
   - **🚚 출고량 입력** — 이번 달 출고량 넣기 ★ 매달 반복하는 작업
   - **📦 재고 추이 보기** — 특정 상품의 월별 재고 텍스트로 확인
   - **🔮 예측 생성** — 새 예측 만들기 (예전 예측은 안 지워짐)
   - **📊 예측 vs 실제 비교** — 오차율까지 자동 계산
   - **📤 엑셀로 내보내기** — 결과를 xlsx로
   - **📈 대시보드 보기** — 실적/예측을 인터랙티브 HTML 대시보드로 시각화
   - **🌱 씨드 데이터 재생성** — 실수로 데이터 꼬였을 때 초기 상태로 리셋
3. `F5` 누르면 화면 위쪽에 입력창이 뜨면서 상품명·연월·수량 등을 물어봐요. 채워 넣고
   Enter 치면 하단 터미널에 결과가 바로 출력돼요.

옵션 조합이 복잡한 명령(`--exclude` 등 세부 플래그 여러 개를 한 번에 쓰고 싶을 때)은
F5 대신 VS Code 하단 터미널(``Ctrl+` ``)을 열어서 이 문서 아래쪽 "기본 사용법" 그대로
타이핑하는 게 더 편해요.

**자주 쓰는 명령은 태스크로도 등록해뒀어요**
`Ctrl+Shift+P`(또는 `Cmd+Shift+P`) → "Tasks: Run Task" 입력 → 아래 중 선택:
- 상품 목록 보기 / 필요 패키지 설치 / 엑셀로 내보내기 / 씨드 데이터 초기화

## 기본 사용법

### 1. 상품 목록 확인
```bash
python3 forecast_tool.py list
```

### 2. 특정 상품 실적 이력 보기
```bash
python3 forecast_tool.py history 스프레이_아보카도200
```

### 3. 이번 달 실제 실적 입력 ★ 매달 반복하는 핵심 작업
```bash
python3 forecast_tool.py add-actual 스프레이_아보카도200 2026-07 1850
```
> `스프레이_아보카도200` 상품의 `2026-07`(7월) 실적이 `1850`개였다는 뜻이에요.

### 3-1. 재고 관리 (2026-06부터) ★ 매달 반복하는 작업

**재고를 직접 세어본 값 입력** (최초 1회, 그리고 실사할 때마다) — 이 값을 기준으로 이후 출고량이 자동 차감돼요.
```bash
python3 forecast_tool.py set-stock 스프레이_아보카도200 5000 --asof 2026-05
```
> `--asof`를 생략하면 이번 달 기준으로 저장돼요. 재고를 다시 세어봤을 때(입고 반영 등) 같은 명령으로
> 최신 실사값을 다시 입력하면 그 시점부터 새로 차감이 시작돼요.

**이번 달 출고량 입력** ★ 매달 반복
```bash
python3 forecast_tool.py add-shipment 스프레이_아보카도200 2026-06 800
```
> `2026-06`에 `800`개가 출고됐다는 뜻이에요. 직전 재고에서 자동으로 차감돼서 계산돼요.

**월별 재고 추이 확인**
```bash
python3 forecast_tool.py stock 스프레이_아보카도200
```

### 4. 예측 생성
```bash
python3 forecast_tool.py forecast 스프레이_아보카도200 2026-07 --months 6 --method seasonal --scenario base
```
- `2026-07` : 예측을 시작할 월
- `--months 6` : 몇 개월치 예측할지 (기본 6)
- `--method` :
  - `seasonal` (기본값) — 해당 월의 **과거 실적 평균을 그대로 반복**. 예를 들어 9월을
    예측할 때 과거의 모든 9월 실적을 평균 냄. 특정 달의 튄 값(광고 스파이크 등)에
    상대적으로 덜 흔들려요. 대화에서 "낙관 시나리오"로 썼던 방식이에요.
  - `trend` — **최근 N개월 평균 × 계절지수**. 최근 추세를 더 강하게 반영해요.
    대화에서 "신중/비관 시나리오"로 썼던 방식이에요.
- `--scenario` : `base`(×1.0) / `optimistic`(×1.10) / `conservative`(×0.90) 중 선택하거나,
  숫자를 직접 넣어도 돼요 (예: `--scenario 1.15`)
- `--window 4` : `trend` 방식에서 "최근 N개월"의 N (기본 4)
- `--exclude 2026-03,2025-09` : 광고 스파이크 등 이상치로 판단되는 달을 계산에서
  제외하고 싶을 때 사용 (콤마로 여러 달 지정 가능)

### 5. 예측 vs 실제 비교
```bash
python3 forecast_tool.py compare 스프레이_아보카도200
```
그동안 쌓인 모든 예측(vintage)을 실제값과 나란히 보여주고, 실제값이 들어온 달은
오차율(%)까지 계산해줘요. 아직 실제값이 없는 미래 달은 "(대기중)"으로 표시돼요.

### 6. 전체 데이터 엑셀로 내보내기
```bash
python3 forecast_tool.py export
```
`forecast_export.xlsx` 파일이 생성돼요 (경로 지정하려면 `--out 경로.xlsx`).
3개 시트로 구성돼요:
- **실적** — 전 상품 월별 실제 실적
- **예측기록** — 그동안 생성한 모든 예측(vintage 포함)
- **예측vs실제** — 예측과 실제를 나란히 비교, 오차율 포함

### 7. 인터랙티브 대시보드로 시각화
```bash
python3 forecast_tool.py visualize
```
`forecast_dashboard.html` 파일을 생성하고 기본 브라우저로 자동으로 열어요
(경로 지정하려면 `--out 경로.html`, 자동으로 안 열리게 하려면 `--no-open`).
외부 라이브러리 없이 순수 HTML/CSS/JS로만 만들어져서 인터넷 연결 없이도 열 수 있어요.
- **브랜드별 월간 실적 추이** — 4개 브랜드 실적 합계를 한 차트에서 비교
- **월별 계절성 지수** — 브랜드별로 어느 달이 성수기인지 한눈에
- **상품별 개요** — 21개 SKU 스파크라인 그리드, 브랜드 필터·검색 가능
- **상품 상세** — 카드를 클릭하면 실적 추이 + (있다면) 예측 vintage 오버레이 + 예측vs실제 오차율 표시
- **재고 추이 (막대그래프)** — `set-stock`/`add-shipment`로 입력한 재고가 있는 상품은 상세 화면에
  월별 재고 잔량이 막대그래프로 표시돼요. 막대에 마우스를 올리면 그 달 출고량까지 확인할 수 있어요.

데이터를 갱신한 뒤(`add-actual`, `forecast` 실행 후) 다시 실행하면 최신 데이터로 다시 만들어져요.

## 새 상품 추가하고 싶을 때

`data/history.json`을 직접 열어서 아래 형식으로 추가하면 돼요.

```json
{
  "새상품명": {
    "2025-01": 1200,
    "2025-02": 980
  }
}
```

`data/products.json`에도 브랜드 정보를 같은 방식으로 추가해주면 `list` 명령에 브랜드명이
표시돼요 (안 넣어도 동작은 해요).

```
demand_forecast_tool/
├── forecast_tool.py       실행 파일 (이것만 돌리면 됨)

├── README.md               이 파일
├── forecast_dashboard.html  visualize 명령으로 생성되는 대시보드 (git에는 안 올라감)
└── data/
    ├── history.json        실적 데이터 (add-actual 로 계속 채워나감)
    ├── forecasts.json       예측 기록 (forecast 실행할 때마다 누적)
    ├── products.json        상품-브랜드 매핑
    └── inventory.json       재고 데이터 (set-stock 실사값 + add-shipment 출고량)
```

## 매달 반복하는 루틴 (권장)

1. 이번 달이 지나면 `add-actual`로 지난달 실적 입력
2. `add-shipment`로 지난달 출고량 입력 (재고는 자동으로 차감됨)
3. `forecast`로 앞으로 6개월 예측 새로 생성 (기존 예측은 그대로 남아있음)
4. `compare`로 지난 예측이 얼마나 맞았는지 확인
5. `visualize`로 대시보드를 새로 만들어 실적·재고 추이를 한눈에 확인
6. 필요하면 `export`로 엑셀 뽑아서 회의자료로 활용
